CodeAlpha Basic Network Sniffer

Project Description

A Python-based network sniffer that captures and analyzes network packets using Scapy.

Technologies Used

- Python
- Scapy
- Npcap

Features

1. Captures network packets.
2. Displays source IP address.
3. Displays destination IP address.
4. Identifies network protocols (TCP, UDP, ICMP).
5. Displays packet size.
6. Displays packet statistics.

How to Run

python sniffer.py
